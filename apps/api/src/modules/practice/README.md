# The practice bank

Aptitude and coding practice items (prompt 2, G4). See [`docs/specs/practice.md`](../../../../../docs/specs/practice.md).

## What may go in

- **Original questions only.** Never import or paste copyrighted question dumps: company test papers, coaching books, question sites or "previous year" collections. A question "asked by company X" may be described in your own words (with new numbers) and tagged with the company.
- The starter set in `starter-items.ts` was written for CampusLink. Keep its `ref`s permanent; add new items with new refs.
- AI drafts are original by instruction (`practice-tasks.ts`) and always wait for a faculty decision. Check every answer before approving one: drafts can be wrong.
- Every item has an explanation a student can learn from, and only one right answer.

## Where it runs

Coding answers run only on the platform's self-hosted Judge0 (`code-runner.ts`), never on a third-party service.
