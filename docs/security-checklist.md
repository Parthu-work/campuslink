# Security checklist (OWASP ASVS-aligned)

Legend: ✅ done and tested · 🟡 partial · ⏳ planned (phase)

| Area           | Control                                                                                                                                                                                           | Status                                  |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Validation     | Zod strict schemas on every body, query and param; unknown keys rejected                                                                                                                          | ✅                                      |
| Validation     | `$`/dotted/prototype keys rejected at the edge (NoSQL injection, prototype pollution)                                                                                                             | ✅                                      |
| Output         | API returns JSON only; React escapes output; the QR SVG is rendered via `<img>` data URI                                                                                                          | ✅                                      |
| Output         | Rich text stored as plain text (empty-allowlist sanitiser, bidi stripped); markdown subset rendered as React elements; https-only links (ADR 0007)                                                | ✅                                      |
| Headers        | Helmet: CSP `default-src 'none'` for the API, nosniff, frame-ancestors none, `Cache-Control: no-store`; HSTS in production                                                                        | ✅                                      |
| Headers        | Web: strict CSP (`script-src 'self'`), HSTS 2 years, Permissions-Policy, COOP/CORP, DENY framing in `deploy/nginx`; tested; end-to-end suite runs under it                                        | ✅                                      |
| Logs           | Access log is an allowlist (id, method, path, status): no headers, query strings, IPs or user agents                                                                                              | ✅                                      |
| Privacy rights | Self-service export (audited, rate-limited) and deletion with a grace period, password re-check, sign-out everywhere, then erasure by every module                                                | ✅                                      |
| Backups        | age-encrypted (public-key recipients), checksum, decrypt-before-restore, restore to a separate database only, monthly drill                                                                       | ✅                                      |
| CORS           | Exact allowlist with single-label wildcard subdomains; spoofing tests                                                                                                                             | ✅                                      |
| AuthN          | argon2id (19 MiB, t=2), zxcvbn ≥ 3, HIBP k-anonymity (fails open)                                                                                                                                 | ✅                                      |
| AuthN          | Lockout, rate limits, enumeration-safe flows                                                                                                                                                      | ✅                                      |
| AuthN          | Rotating refresh tokens with reuse detection, revocation, httpOnly/Strict cookies                                                                                                                 | ✅                                      |
| AuthN          | CSRF double-submit plus Origin check for cookie endpoints                                                                                                                                         | ✅                                      |
| AuthN          | TOTP 2FA, mandatory for admins; replay protection; hashed recovery codes                                                                                                                          | ✅                                      |
| AuthN          | Session and device list with revoke                                                                                                                                                               | ✅                                      |
| AuthZ          | Deny-by-default; registry-driven role × endpoint matrix test                                                                                                                                      | ✅                                      |
| AuthZ          | Object-level checks (IDOR) and vertical-escalation guards                                                                                                                                         | ✅                                      |
| Tenancy        | Central plugin, no-context-throws, cross-tenant suites in CI                                                                                                                                      | ✅                                      |
| Tenancy        | File isolation suite (download, avatar, ID card, chat attachments); socket suite (handshake tenant binding, per-user rooms)                                                                       | ✅                                      |
| Rate limits    | Redis-backed: auth, signup, email actions, MFA, refresh, admin writes, global                                                                                                                     | ✅                                      |
| Rate limits    | Uploads (20/h), search (60/min), verification codes (10/h), requests (10/h), messages (30/min), reports (20/h), push (20/h), posting (20/h), interactions (120/min), Q&A (10/h), referrals (10/h) | ✅                                      |
| Uploads        | Magic-byte sniffing, size caps, random keys, sharp re-encode (EXIF stripped), zip-bomb pre-scan, AV hook, sandboxed CSP                                                                           | ✅                                      |
| SSRF           | Safe fetcher (HTTPS, pinned DNS, public IPs only, redirect revalidation, caps) for imports, web push and bot checks; push endpoints limited to known push services                                | ✅                                      |
| Secrets        | Env-only; production refuses placeholder secrets; gitleaks in CI; no secrets or bodies in logs (Pino redaction)                                                                                   | ✅                                      |
| Crypto at rest | AES-256-GCM field encryption plus blind index (TOTP secrets, list emails and phones, profile phone)                                                                                               | ✅                                      |
| Audit          | Append-only log (update and delete hooks throw); logins, roles, verification, exports, platform actions                                                                                           | ✅                                      |
| Dependencies   | Lockfile, `pnpm audit` in CI                                                                                                                                                                      | ✅                                      |
| Bot protection | Turnstile-style adapter on sign-up and mentorship requests (fails closed; disabled locally)                                                                                                       | 🟡 server side only; web widget pending |
| Verification   | OTP hashed, 10-minute expiry, 5 attempts, single use; each record claimable once; claimed and unknown rolls answer alike                                                                          | ✅                                      |
| Imports        | CSV formula-injection guard on error reports; per-row validation; idempotent re-import; rollback keeps claimed records                                                                            | ✅                                      |
| Idempotency    | `Idempotency-Key` on requests, responses, reschedules and messages (replay, 422 on body mismatch, per user and tenant)                                                                            | ✅                                      |
| Realtime       | Socket auth equals HTTP auth; Origin allowlist; disconnect at token expiry and on suspension; strict client event schema                                                                          | ✅                                      |
| Messaging      | No cold DMs; participants-only reads; encrypted bodies; reports carry snapshots; block closes every channel                                                                                       | ✅                                      |
| Video          | Non-guessable rooms rotated on reschedule; links only for participants within the join window; optional Jitsi JWT                                                                                 | ✅ (self-host Jitsi for expiring links) |
| Feed media     | Upload-then-claim (owner + purpose, single use), MP4/MOV sniffing, 60 s duration cap, video metadata wiped, images re-encoded                                                                     | ✅                                      |
| Moderation     | Reason shown to the author, one appeal, second moderator to uphold, append-only action log                                                                                                        | ✅                                      |
| Ingestion      | robots.txt (RFC 9309), identifying UA, conditional requests, Retry-After and back-off, XXE-safe parsing, SSRF-safe fetcher, snippet + link-out only                                               | ✅                                      |
| Jobs           | Posting by verified alumni and staff only, https apply links, reportable and moderatable listings, source adapters through the SSRF-safe fetcher                                                  | ✅                                      |
| Roadmaps       | Review by someone other than the editors before publishing, strict content schema with cycle checks, plain text, https-only cited links, weekly link check, audit of review decisions             | ✅                                      |
| Gamification   | Ledger dedupe and caps, no self-awards, audited revocation, redemption lock and atomic stock, opt-in leaderboards                                                                                 | ✅                                      |
| Events         | Atomic capacity, link visible to people going only, versioned reminders, escaped .ics, host-only management                                                                                       | ✅                                      |
