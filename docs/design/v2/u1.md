# U1 · Design language v2 and primitives

The decision and token table live in `docs/adr/0015-design-language-v2.md`. This note is the phase's design doc (prompt 3, "How to work").

## Who and what for

Everyone, on every screen: the tokens and primitives that U2–U9 build screens from. The job is to make the next action obvious and the screen calm before any screen is rebuilt.

## Problems from §3 this phase addresses

| Finding | What U1 does                                                                                                                 | Finished in |
| ------- | ---------------------------------------------------------------------------------------------------------------------------- | ----------- |
| A3      | `ListRow`, `PersonCard`, `StepTrack`, `ActionCard`, `PageHeader` wrap titles and names; nothing truncates                    | U2–U9       |
| A4      | Three radii; flat cards; `ListSection` replaces cards of rows; no icon-in-circle in `EmptyState`; one button height per size | U2–U9       |
| A5      | `eyebrow` is sentence case in the UI face everywhere it is used (40 places changed at once)                                  | Done        |
| A6      | `PageHeader` moves `intro` behind "About this"; every screen that passed `intro` lost its paragraph above the fold at once   | Done        |
| A7      | Button hierarchy (primary only for the one main action; secondary neutral; tertiary text); flat primary without a shadow     | U2–U9       |

## States

- Loading: `SkeletonRow`, `SkeletonCard`, `SkeletonChart` mirror the final shapes (same row height).
- Empty: `EmptyState` with a faded `preview` of what will appear and one action.
- Error and offline: unchanged primitives (`ErrorState`, the offline banner); U10 restyles them.
- Minor and read-only: no change in U1 (screens decide what to show).

## Acceptance

- Tokens: `tokens.test.ts` (six steps, 12.5 px floor, +15%, +2 px for Telugu and Devanagari, three radii, motion, flat cards, 44 px compact rows); `palette.test.ts` (status inks ≥ 5.5:1 on every college's surfaces; surfaces distinct; true dark).
- Primitives: `primitives.a11y.test.tsx` (axe, no violations; loading keeps the label; row link and trailing action; step track numbering and states; countdown not live).
- Style guide: every primitive in both themes with Telugu and Hindi rows and compact density.
- Gates: format, lint, typecheck, unit and API tests, build, bundle budget.
